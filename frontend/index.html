How to use J/Z
  1. Press Record J/Z once.
  2. Wait for the 3-second countdown.
  3. Draw J or Z once, clearly and naturally, during recording.
  4. The result is detected automatically.
Settings

Hand tracking runs locally in your browser for faster performance. Hold a static letter steady for about one second to type it. Release or change the hand pose before repeating the same letter.
